# ПЭ3 Генератор v0.66

Программа для Windows 10/11 x64, формирует перечень элементов (ПЭ3) из схем **Altium Designer** (`.SchDoc`) и **P-CAD** (`.sch`), поддерживается bin и ASCII. Результат сохраняется в XLSX или PDF.

## Сформировать перечень

1. Добавьте одну или несколько схем одного документа.
2. Выберите XLSX или PDF и укажите путь в поле **Файл результата**.
3. Нажмите **Сформировать перечень**.

Для PDF нужен шрифт **ISOCPEUR**. Установите его в Windows или поместите `ISOCPEUR.ttf` в папку `assets/fonts` рядом с EXE.

## Как заполняется перечень

- **Altium.** Название берётся из `Title` или `Наименование`, обозначение — из `DocumentNumber` или `Обозначение_Код`. Поддерживается кириллица в ASCII SchDoc с UTF-8 BOM.
- **P-CAD.** Программа сначала ищет реквизиты в **Design Info → Fields**. Для каждого пустого реквизита она пытается извлечь значение из имени файла.
- **Повторы позиций.** При конфликте наименований программа записывает варианты через ` / ` в одну строку с количеством 1 и отмечает повтор в протоколе.
- **Лист регистрации изменений.** Программа добавляет его, когда перечень занимает три страницы или больше. Для XLSX из Altium и P-CAD используется одна форма.
